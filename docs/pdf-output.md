# One-way print/PDF output

Open a complete saved calculated revision and choose **Print / Save PDF** in the Visual Flight Log panel. In the browser print dialog, select **Save as PDF**, landscape paper, and disable browser-supplied headers/footers if a clean worksheet is preferred. The output is generated entirely in the browser from that immutable revision and its saved weather evidence; it neither refreshes weather nor uploads planning data. A draft, infeasible calculation, or revision missing its referenced weather evidence cannot be printed through this action. There is no PDF import path.

The printable sheet includes route and aircraft identity, planned departure, revision and forecast times, all calculated phase rows, generated TOC/TOD and transition boundaries, separate fuel buckets, source-snapshot references, the field-elevation wind assumption, per-row assumptions, and deliberate overrides. Numeric display rounding does not change the saved calculation. This is a teaching and planning aid, not an official weather briefing or complete preflight plan.

The export relies on the browser's PDF print destination rather than a bundled PDF library. This avoids sending local data to a server and avoids an additional browser dependency, but it means the user chooses the PDF filename and destination in the print dialog. The printed layout was visually checked with the synthetic five-row complete-flight fixture on one landscape page and a 40-row pagination stress case on three landscape pages; the latter repeated table headings and did not split rows.
