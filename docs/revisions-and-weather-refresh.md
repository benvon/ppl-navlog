# Revisions, overrides, and weather refresh

The browser stores each plan revision as a distinct immutable record. The planner lists local plan families and revisions; opening another revision requires confirmation when a revision is already open because unsaved form or draft edits may be discarded. The comparison view summarizes departure time, selected forecast period, aircraft profile, route points, weather evidence IDs, and calculation status. Full row-level calculations remain in each revision's inspector.

A cruise-TAS override requires an explicit unlock, an impact explanation, and a confirmation checkbox. The original aircraft default remains in the value provenance and the affected leg is visibly marked `OVERRIDDEN`. Saving the same ordered route preserves leg identities and their overrides. Changing the route structure generates new leg identities and intentionally drops leg-specific overrides so that they cannot silently apply to a different segment. Restoring a default is a separate deliberate action. A changed aircraft profile should be reviewed before recalculation.

Weather refresh starts from a saved complete calculated revision. The pilot loads published winds periods, explicitly chooses one valid for the planned departure, and requests refresh. The application recalculates before writing anything. If weather, calculation, or immutable evidence is missing or infeasible, no child revision is saved and the parent remains available. A successful refresh atomically saves a `weather-refresh` child, new immutable source snapshots, and a bounded comparison against the parent. New snapshot IDs and retrieval timestamps are disclosed as provenance but do not alone count as changed weather content.

Local JSON backup downloads all plans, profiles, revisions, and weather evidence. Import accepts only the validated versioned format and merges new records atomically; a conflict or invalid file writes nothing. Import does not replace existing browser data, and no plan data is uploaded. The 1 MB import cap is enforced before reading a selected file and again during parser validation.
